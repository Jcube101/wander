# Security

Wander's whole point is that a trip is visible only to the people who were on it. If you find a way around that — reading a protected trip without being in its Access group, getting the Worker to serve a file outside its allow-list, a path that Access and the Worker read differently, a token or local path leaking into published files — please report it privately:

- GitHub → this repo → **Security** → **Report a vulnerability**.

Please don't open a public issue for it. This is a spare-time project, so a reply may take a few days; I'll confirm, fix and credit you (if you like) once it's sorted.

Out of scope: Cloudflare's own services (report those to Cloudflare), and anything that needs access to the owner's machine or Cloudflare account.
