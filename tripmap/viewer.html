Trip

How do I…

  • Add new photos/videos → drop them anywhere in the trip folder (not _tripmap), then ⋯ → Scan for new files. Restarting the launcher doesn't scan.
  • Place an unplaced shot → No location filter → select → the map shows its neighbours → [ / ] or click the map.
  • Fix a day or time → select → Move to day… / Shift time.
  • Hide a shot → select → Archive (A). Bring back → Archived filter → Restore (Shift+A).
  • Change the cover → select one photo → Set as cover.
  • Make changes live → Apply to map, then Publish.
  • A shot is missing after a scan → check the launcher window. Files with only a date that falls >1 day outside the trip are skipped; anything in _tripmap is ignored.

Shortcuts

Click shots to select · Shift-click for a range · Double-click to view.

With shots selected, click the map or a pin to place them. Drag a pin to move it.

Selecting a shot shows where it happened: its pin, or the nearest placed shots before and after it.
